# Comparing Numbers

<!-- synced-problem-statement -->

Given two integers, $X$ and $Y$, identify whether $X \lt Y$ or $X \gt Y$ or $X = Y$.   


Exactly one of the following lines:   
- _X is less than Y_   
- _X is greater than Y_   
- _X is equal to Y_
